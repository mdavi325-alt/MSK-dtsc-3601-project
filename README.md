# Criminal Justice Project - MSK

**Overview:** This project investigates how victim characteristics, incident details, and neighborhood socio-economic factors (e.g., homelessness, age distribution, and population density) can be used to predict the LAPD division in which automobile theft is most likely to occur. Since automobile theft remains one of the most common property crimes in Los Angeles, our goal is to build data-driven models (e.g., Logistic Regression, Decision Trees, Risk Terrain Modeling) that not only improve predictive accuracy but also provide interpretable and fair insights. Beyond academic interest, the project has practical implications for reducing crime and allocating resources more effectively for prevention.
